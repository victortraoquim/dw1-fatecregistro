Vantagens dop CSS Externo

  • Separação completa entre conteudo (html) e design (CSS)
  • Reutilização em múltiplas páginas
  • Facilota a manutenção do código
  • Melhor organização do projeto
  • Pode ser armazenad no cache do navegador, melhorando a performance
